 # Email Classifier

Классификатор email-писем для определения спама и фишинга на основе ML-модели.

## Требуемые зависимости для запуска приложения

- Docker
- Docker Compose
- Make

## Запуск

1. Склонировать репозиторий:

   ```bash
   git clone https://github.com/giorgioarmani2005/email-classifier.git
2. Перейти в каталог проекта:

   ```bash
   cd email-classifier
   ```

4. Собрать и запустить приложение:

   ```bash
   make
   ```

5. Открыть в браузере:

   ```
   http://localhost
   ```

## Очистка системы от данных приложения

Для того, чтобы остановить и удалить контейнеры, сети и volumes, выполните в корне проекта:

```bash
make clear
```

После этого можно удалить папку с проектом.
