## ***Классификатор писем***

Для сборки и запуска нужны docker, docker compose. 

Приложение позволяет пользователю проанализировать письмо электронной почты (или же текст) на наличие возможного спама, фишинга. Полученный результат основан на классификации модели.
## *** Инструкция по запуску***

1) Склонировать репозиторий;
2) Перейти в каталог проекта; 
3) Запустить команду `make` из корня проекта;
4) В браузере вбить URL - http:localhost 

 Если приложение дальнейшему пользованию не подлежит, выполните команду `make clear`, а после удалите папку с проектом.
